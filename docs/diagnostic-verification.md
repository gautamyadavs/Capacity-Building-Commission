## Content-purpose review

Orientation explains the public task, eight reasoning targets, assistance conditions, preservation boundary and access/recovery. These support interpretation or operation. The general objective/criterion reference is optional and gives no case answer. Access/support notes are optional and impose no AI/source disclosure requirement.

Case screens contain a neutral case/phase heading, exact task, every controlling fact and exact prompts. Updates expose earlier facts and submitted text as an in-page reference. This reduces recall/navigation demands while retaining uncertainty, competing duties, harms and authority limits. Preserved responses repeat the exact prompt for interpretation; no field asks officers to rewrite an earlier answer. The interface has no decorative imagery, animation, sound, motivational quote or theory section.

Ended views display submitted records, incomplete opportunities, actual human feedback and file transfer/recovery. Review-only views contain descriptors, phase mapping, evidence locations, source/version material, authored illustrations and calibration guidance because those serve judgement. Illustrations are never automatic officer feedback. The optional future practice sequence is not implemented.

KLI, coherence, neutral signaling, explanation and evidence-linked feedback are bounded design guidance from document 06. No software result validates a knowledge-component model, establishes an optimal format, measures learning gain or demonstrates programme causation.
